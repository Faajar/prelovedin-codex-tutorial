## 1. What Is OpenAI Codex?

OpenAI Codex is an AI coding agent that can help developers understand existing code, implement features, debug issues, and improve software.

I use Codex Desktop to work directly with my development projects.

## 2. Getting Started

To follow this tutorial, you need:

- OpenAI Codex Desktop
- An existing coding project
- Git and GitHub
- A development environment for your chosen programming stack

Open your project folder in Codex Desktop to begin.

## 3. Understanding the Project

Before making changes, I recommend asking Codex to understand the existing codebase.

**Example prompt:**

> Analyze this project and explain its folder structure, main components, and application workflow. Do not modify any files yet.

Review the explanation before continuing.

## 4. Building Features with Codex

Codex can help implement new functionality using natural-language instructions.

**Example prompt:**

> Inspect my existing marketplace application. Suggest an implementation plan for improving its product search experience. Explain which files would change before writing code.

After reviewing the plan, you can ask Codex to implement the approved changes.

## 5. Reviewing and Testing

AI-generated code still requires developer supervision.

My recommended workflow:

1. Review the proposed changes.
2. Understand the modified files.
3. Run the application locally.
4. Test the affected functionality.
5. Fix any problems before deployment.

## 6. My Project: PrelovedIN

Using Codex does not eliminate the developer's responsibility. Planning, reviewing, testing, and deciding what to deploy remain important.
